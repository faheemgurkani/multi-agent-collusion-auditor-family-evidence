# multi-agent-collusion-auditor-family-evidence

Experiments on multi-agent collusion: how an auditor's model family, and whether it sees messages, actions, or both, changes what it detects.

Research conducted at the [Apart Research AI Collusion Research Sprint](https://apartresearch.com/sprints/ai-collusion-research-sprint-2026-10-23-to-2026-10-25), 23–25 October 2026. No prior work. The sprint is co-organized by Apart Research, Poseidon Research, and AE Studio.
